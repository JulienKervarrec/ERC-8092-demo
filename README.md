# ERC-8092 Demo

A Next.js demo for [ERC-8092](https://github.com/ethereum/ERCs/pull/1377) Associated Accounts.

## Install

```bash
pnpm install
```

## Run

```bash
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000).


## Parcours francais

Une lecture pedagogique en francais de ce depot est disponible dans docs/fr/README.md. Elle couvre la structure imbriquee AAR/SAR d ERC-8092, sa signature EIP-712, le role des adresses interoperables ERC-7930, les trois types de comptes signataires geres (EOA, contrat deploye, contrat contrefactuel), et les deux backends de stockage (on-chain et hors-chaine) avec leur mecanisme de revocation.
