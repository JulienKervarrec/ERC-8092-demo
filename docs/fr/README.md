# Parcours francais : ERC-8092-demo (associations verifiables entre comptes)

Lecture pedagogique du depot base/ERC-8092-demo : une application Next.js illustrant ERC-8092 (Associated Accounts), un standard Ethereum en brouillon permettant a deux comptes de declarer, prouver et revoquer publiquement une relation entre eux.

Sommaire :

Chapitre 1 Presentation de ERC-8092-demo. Chapitre 2 La structure imbriquee de l association et sa signature EIP-712. Chapitre 3 Adresses interoperables, pourquoi ERC-7930 plutot qu une adresse brute. Chapitre 4 Trois types de comptes signataires, EOA, contrat deploye, contrat non deploye. Chapitre 5 Deux backends de stockage interchangeables, et la revocation en pratique. Chapitre 6 Limites et perimetre de ce parcours.

Ce parcours est une lecture pedagogique du code source et de la documentation du depot, sans installation ni execution du projet.
